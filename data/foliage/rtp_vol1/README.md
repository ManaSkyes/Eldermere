# RTP Vol.1 tree textures

Source: the installed Unity project at `Assets/RTP Vol.1/Materials`.

Eldermere uses the two leaf maps and two bark maps in its existing instanced tree atlas for broadleaf and birch variants. The source FBX models remain under `art/foliage/rtp_vol1/`; the game still builds its own tree geometry so its wind, shadows, distance levels, and impostors continue to work.

These are embedded game assets, not a standalone texture pack. Follow the original asset license if distributing the game.
