# Grass Flowers Pack Free

Source package: **Grass Flowers Pack Free**, Unity Asset Store product ID `138810`, package version `1.1` (as recorded by the Unity import metadata).

The grass and flower TGA textures were converted to PNG for Eldermere's browser renderer. The ground grass texture was reduced from 4096 × 4096 to 2048 × 2048 and saved as JPEG for a smaller runtime file. `src/gfx/foliage.js` uses the grass and flower images on crossed alpha cards; Eldermere's own instancing, wind, and distance handling remain in use.

These files are included as embedded game assets under their applicable Asset Store license. Do not redistribute this folder as a standalone asset pack. The installed package contains no tree meshes or prefabs.
